# Report page design

## 1. Executive overview

Show approved budget, expenditure, commitments, remaining budget, active projects, on-time reporting and open high-severity risks. Add a quarterly trend and a theme-level portfolio view. Every finance card should state the selected period and currency.

## 2. Finance and delivery

Compare approved budget with expenditure and commitments by project and fiscal year. Add expenditure trend, budget utilization and milestone status. Include project drill-through and make the accounting period visible.

## 3. KPI and reporting health

Show quarterly KPI values and targets, expected versus received submissions, overdue obligations and completeness by project. Keep KPI units separate and label missing values clearly.

## 4. Research and public context

Show recorded fictional research outputs by type/year. In a separate area, explore selected public energy indicators by country/year. Label the public source and state that it is context, not a program outcome.

Use high-contrast colors, descriptive titles, clear units, accessible labels and definition tooltips. Add a data-as-of date and source note to each page. Avoid dual axes unless clearly justified.
