# Public context dataset

`global-data-on-sustainable-energy.csv` is the *Global Data on Sustainable Energy (2000–2020)* dataset by Ansh Tanwar, obtained from [Kaggle dataset version 7](https://www.kaggle.com/datasets/anshtanwar/global-data-on-sustainable-energy/versions/7).

The Kaggle dataset page states the license as **CC BY 4.0**. Please review the dataset page and [Creative Commons Attribution 4.0 terms](https://creativecommons.org/licenses/by/4.0/) before redistributing or adapting it. Attribution: “Global Data on Sustainable Energy (2000–2020), Ansh Tanwar, Kaggle, version 7, CC BY 4.0.”

The file contains 3,649 data records and 21 columns in this copy. It spans country/entity and year records for 2000–2020. Blank fields are missing values, not zero. Field descriptions are listed in [`../../docs/public_data_dictionary.md`](../../docs/public_data_dictionary.md).

This is a separate context source, not a measure of the synthetic research program's performance or impact.
